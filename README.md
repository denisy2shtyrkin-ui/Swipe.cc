# Swipe.cc

**🔒 Без рекламы и вирусов - 100% чистый код**

Swipe.cc - это современный Roblox скрипт с модульной структурой и множеством функций.

## 🚀 Быстрая загрузка

Скопируйте и вставьте в executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/denisy2shtyrkin-ui/Swipe.cc/main/Swipe.cc/Swipe.cc.lua"))()
```

## ✨ Возможности

### GUI
- Современный draggable интерфейс
- Тёмная тема с настраиваемым акцентным цветом
- 6 вкладок: Main, Player, Visuals, World, Misc, Settings
- Анимации, уведомления, поиск по функциям
- Сохранение настроек

### Player функции
- WalkSpeed & JumpPower слайдеры
- Infinite Jump, Noclip, Fly
- Click TP (Ctrl + ЛКМ)
- Anti-AFK, God Mode

### Visuals
- ESP (Box, Name, Distance)
- Fullbright, Remove Fog
- FOV Changer, Crosshair
- Chams через Highlight

### World
- Time of Day
- Remove Shadows
- Ambient Changer
- Remove Textures
- Gravity changer

### Misc
- Chat Spy
- Rejoin / Server Hop

## 🔧 Поддерживаемые executors

- Script-Ware
- KRNL
- Fluxus
- И другие популярные executors
